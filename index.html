About Me

Engineering Ideas
Into Reality

From internship to owning full-stack architecture and production cloud infrastructure.

I'm a Full Stack Developer with 4+ years of experience building, deploying and operating web and mobile applications – from React Native and React.js front ends to Node.js REST APIs, MySQL data models, and the AWS and Microsoft Azure infrastructure they run on.

As a Senior Software Engineer at EarnWealth Solutions I've shipped 9 full-stack applications end to end, including SpeedTech.AI (Raiya), an AI-powered telecalling platform. The work spans API design, payment, third-party and SIP/telephony integrations, GitHub Actions CI/CD across 9 repositories, and troubleshooting live systems through log analysis.

I started as an intern at Aadi Technology, then led mobile delivery at Appzia Technologies – taking apps from requirements to the App Store and Google Play, coaching junior developers and working directly with clients. I work in Agile/Scrum teams and care about the parts users never see: predictable deploys, APIs that fail clearly, and interfaces that stay fast on mid-range hardware.

End-to-End Ownership Architecture, API design, front end, cloud deployment and production release.
